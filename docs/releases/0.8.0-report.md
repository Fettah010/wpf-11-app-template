## 3. Research and architecture decisions

- Engine mechanics proven by spike, then by real matrix (not assumed).
- Shell/ThemeDefault value-injection CUT: `replaces` uses choice keys
  (custom `value` ignored — observed in generated output); multi-line `#if`
  initializers are invalid C# in repo builds. Runtime switching documented.
- `bin/obj` excludes need `**/` glob form; `eng/test-templates.ps1`
  excluded from output; `UpdateChannel` moved to `ShellSettings.cs` so the
  enum never depends on an excludable module; test files are preset-aware
  (excludes + `#if` asserts).
- One load flake in Full tests under matrix pressure (4/4 green solo);
  existing poll guards hold; recorded.
- Item templates use `sourceName` for `-n` (not replaces/fileRename).
