## 1. Outcome and success definition

Motion becomes a system: tokenized durations/easings, `Auto/Full/Reduced/Off`
profiles honoring the OS animation setting and render tier, page-entrance
transitions, and a dedicated switchable effects demo (ripple + animated
gradient). Expensive paths stay off by default or behind toggles; reduced
motion always works.

Measurable success: smoke green; entrance plays on navigation and collapses
to instant under reduced motion; effects toggle kills all premium animation;
tests ≥42 passing; startup inside ratified budgets; no new packages.

## 6. Design and architecture

- **Policy:** `Auto` = OS-off→Reduced, Tier0→cap Reduced, else Full.
  `Reduced` = Fast durations, no slide/ripple/gradient. `Off` = instant
  (set final state, start no storyboard). `Full` = everything, user-forced.
- **Entrance:** opacity 0→1 (Standard) + translateY 12→0; Reduced: opacity
  Fast only; Off: set 1, return completed. `FillBehavior.Stop` + snap end
  values in Completed (no frozen半透明 states).
- **Ripple:** click point → ellipse (accent border) expands 0→~120px +
  fades over Deliberate; removed on completion; skipped unless Full +
  EffectsEnabled. Host panel clips (`ClipToBounds`).
- **Gradient:** `LinearGradientBrush` stop offsets animated 0↔1 loop
  (Standard, AutoReverse, RepeatForever); toggle stops storyboard and snaps
  base gradient. One surface on Effects page only.
- **No input blocking:** storyboards never awaited by UI logic; commands
  run independently; max duration 380ms.
- **No new assemblies** (ADR-0003 holds); motion lives in
  `Services/Motion*` + `DesignTokenBootstrap`-style statics where view-bound.

- Ripple/gradient never convey state alone (decorative; demos labeled).
- Storyboard failure → catch in service, snap final state, never crash.
- HC: motion unaffected; backdrop None rule stands.
