## 6. Design and architecture

- **Optionality:** services registered always in the reference app but
  independently inert without configuration (empty feed/URL, tray off by
  default); NOTICEs + DEPENDENCIES record each; 0.8.0 template drops the
  matching file set + registrations + package refs (dashboard precedent).
- **No telemetry:** nothing phones home; update/HTTP only on explicit user
  action or configured feed; diagnostics states say why idle.
- **Data:** `%LocalAppData%/Wpf11AppTemplate/app.db` (`user_version`
  migrations); per-operation connections (no lock held → backup-safe).
- **Logging:** `logs/app-YYYYMMDD.log`, Information app / Warning Microsoft,
  14-day retention; `ILogger<T>` in VMs proves DI (DiagnosticsVM).
- **Update flow:** Disabled (no feed) → Idle → Checking → Available/None →
  Downloading (progress) → Ready → restart; any exception → Failed + message.
- **Backup:** zip `{settings.json, app.db}` (+ versions note); restore
  validates presence, replaces, recommends restart.
- **No new assemblies** (ADR-0003 holds).
