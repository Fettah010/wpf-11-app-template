## 1. Outcome and success definition

The 1.0 surface is frozen, machine-guarded, and packaged: template symbols,
shell contracts, config shape, and generated structure documented as frozen;
a template-symbol freeze test fails any silent rename; the template ships as
a versioned `.nupkg` verified by install-from-package generation; migration
policy and extension points published; full gate green from the candidate.

Measurable success: freeze docs + passing freeze test; nupkg installs and
generates a working app; visit-all-pages UI test green; theme/mode launch
matrix green; tests ≥84; no blocking defects.

## 6. Design and architecture

- **Frozen:** template shortNames + symbol names + choice keys; nav/page
  contracts (`INavigableView<T>`, composition registrations shape);
  `ShellSettings` JSON field set; `appsettings.json` sections;
  generated tree layout. **May still change:** patch-level fixes,
  non-contract internals, docs.
- **Nupkg:** `DevTemWPF.Templates.1.0.0-rc.1.nupkg` built from repo;
  content = template.json + sources mirror; installed + generating in gate.
- **Migration:** 0.x prereleases → regenerate or hand-apply per-version
  notes (changelog is the migration log); no data migration (settings JSON
  is forward-tolerant: unknown fields ignored, missing fields default).
- **Extension points:** AppComposition, service interfaces, token aliases,
  `INavigableView` pages, item templates, settings fields (additive).
