## 3. Research and architecture decisions

- WPF-UI navigation/theme/backdrop verified against live docs + 4.3.0
  assembly metadata + gallery sources → ADR-0005/0006.
- **Stale-docs findings:** no `LeftCompact` (rail=`LeftMinimal`); no
  `NavigationService`/`IPageService` impl in 4.3.0 (v4 provider model);
  `ApplySystemTheme()` takes no backdrop (system mode resolved explicitly).
- **Real crash found + fixed:** re-setting `FluentWindow.WindowBackdropType`
  post-init throws in `SetWindowChrome` (Freezable context) on .NET 10.
  Rule: DP set once in ctor (pre-init); runtime changes via
  `ApplicationThemeManager.Apply` (DWM-only, source-verified safe).
- STA tests: `Xunit.StaFact 4.0.24` (`[WpfFact]`) — MS-PL, test-only.
- Rejected: hand-rolled STA helper (maintained package is smaller risk);
  VM-initiated nav service (no 0.2.0 consumer); VSTest return (blocked).
