## 6. Design and architecture

- **Isolation:** dashboard = `Views/DashboardPage*` + `ViewModels/
  DashboardViewModel` + `Services/SampleDataService` + chart package ref.
  Exclusion rule (0.8.0): drop these files + registrations + nav item +
  package ref. Documented in scaffold contract now.
- **Table:** `ListView` + `GridView` (Time/Name/Category/Status/Value);
  header click → `SortCommand` (toggles direction); `SearchText` →
  `ICollectionView.Filter` (name/category/status); empty → notice block.
- **Master/detail:** table (2*) + detail card (1*); selection drives detail;
  narrow windows: cards wrap, table scrolls horizontally (detail keeps
  min-width; full adaptive reflow deferred with note).
- **Chart:** `LineSeries<double>` weekly values + day labels; VM-owned;
  construction is CLR-only (MTA-safe tests).
- **Stepper:** index 0..2, Next/Back `CanExecute` bounds, `ProgressBar`
  + title/content/summary; state in VM, tested.
- **No new assemblies** (ADR-0003 holds).

## 11. Accessibility, resilience, and fallback plan

- Table headers clickable via keyboard (buttons? GridView headers are
  keyboard-focusable); search labeled; sort direction in header text
  (not color-only); detail labeled; stepper buttons + progress text %.
- Chart has adjacent data table (the activity table) — no data-by-color-only.
- Skia native load failure → chart card shows fallback text? Construction
  failure would break the page — guard: chart wrapped so a load failure
  degrades to the table (try/catch around Series build? Series build is CLR;
  native load happens at render). Documented limitation: render failure
  surface is 0.9.0 hardening.
