## 3. Research and architecture decisions

- **Restart-apply (ADR-0015):** 15+ UI runs switching Sidebar→Top crashed
  intermittently (NaN `DoubleAnimation` during re-template). WPF-UI 4.3.0
  source confirms (`PaneOpen` animates `PaneGrid.Width` with
  `To="{TemplateBinding OpenPaneLength}"`); upstream PR #1012/#1015 fixed
  only the load path. Four mitigations exhausted with evidence (close-first
  + 500 ms settle; transitionless close + Width defuse with checkpoint
  tracing proving the crash precedes replacement; control recreation with
  unbind-first). Launching into any persisted shell never crashes. New
  `D25` tracks the upstream fix; revisit per toolkit upgrade.
- **Route registry over framework:** Dane-ME patterns evaluated as
  patterns-not-dependency; minimal registry + per-key independent opens
  solve the demonstrated gaps (a shared-CTS search-box design was replaced
  after proving it cancels independent documents).
- **Frame-per-tab:** WPF `Page` parents only to `Window`/`Frame`
  (Event-Log-proven crash); documents host pages in chromeless per-tab
  `Frame`s.
- **UI-thread marshaling:** hook continuations resume on threadpool;
  collection/selection/persistence rejoin the dispatcher (`RunOnUiThreadAsync`,
  direct-call fallback without `Application.Current` for tests).
- **Template token rule:** a literal `//#if` inside comments silently
  truncates generated files (proven: 13-line output); matrix asserts zero
  tokens; template guide documents the rule.
- **Single-gesture drag guard:** traced nested modal drags with stale
  sources; guard keeps the first gesture.
- **Rejected:** ModernWPF stacking (no new need), docking suite (no
  consumer), Verify snapshots (license fee), custom top chrome (native Top
  proven working via restart path), tear-out/multi-window (no consumer).

**Drag UI test note (AC05):** `WorkspaceTab_Drag_Reorders` passed 8+
consecutive local runs (plus 5/5 pre-guard), then began failing consistently
on this machine with order unchanged and no app crash. Traced runs prove the
mechanism sound (single `dragstart`, `QueryContinue … keys=LeftMouseButton`,
`effect=Move` on quiet runs) and show focus-loss-cancelled sequential drags
on contested runs; the bounded retry absorbs single episodes but not
sustained contention. Keyboard reorder (Move buttons) is UI-proven on every
run and carries the feature regardless. Remote quiet-runner CI adjudicates
before merge: green → ship gesture; red → remove gesture, keep keyboard
reorder (roadmap's explicit deferral path), before any tag.
