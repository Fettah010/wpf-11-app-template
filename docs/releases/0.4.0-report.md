## 3. Research and architecture decisions

- Snackbar/dialog APIs verified against 4.3.0 sources → ADR-0008.
- `ui:ToggleButton`/`ui:Expander`/`ui:ProgressBar` don't exist (natives,
  implicitly styled) — compiler-corrected.
- `ShowSimpleDialogAsync` needs `Wpf.Ui.Extensions`; dialog host has
  legacy + Ex overloads (fake implements both + obsolete explicitly).
- Observed: command-supplied CancellationToken arrives pre-cancelled under
  the MTP runner (probe: immediate start OK, Delay throws ~instantly).
  Busy demo takes no token (documented); dialog path unaffected (fake ignores
  token; live needs no cancellation). Open question for a toolkit-savvy
  contributor, not a product defect.
