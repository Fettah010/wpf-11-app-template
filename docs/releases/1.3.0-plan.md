## 1. Outcome and success definition

Everyday data-heavy desktop apps become buildable on this template without
replacing its conventions: an editable validated DataGrid sample, a
persisted TreeView sample, a dependable time input, a theme-following
chart with a screen-reader summary, a fully localized gallery, and a
cancellable async pattern — each with a gallery surface, a guide, and
tests. Success = D16/D17/D18 closed with evidence (or explicitly re-scoped),
1k/10k responsiveness measured, and Clean still chart-free.

## 6. Design and architecture

- New gallery **Data** page (`DataPage` + `DataViewModel` + grid/tree/time VMs as needed): nav item `Nav_Data` in all presets (gallery content ships everywhere, established pattern); registrations in `AppComposition`; page follows header/index/scroll standards with its own section index.
- `DataGrid`: native control, explicit columns, `ICollectionView` filter (search box), `SelectedItem` detail line, `RowValidationRules`/`IDataErrorInfo` items (name required, value range), add-row placeholder, `LoadState` (Loading/Loaded/Error + retry), `Load 10,000` stress toggle with count label. Default 200 rows.
- `TreeView`: `TreeNode` model (id/label/children), `IsExpanded`/`IsSelected` two-way, expand/collapse-all commands, expanded IDs persisted to `ShellSettings` (new `ExpandedDataNodes` property, additive), 300-node deterministic tree on page, VM-level 10k correctness test.
- Time: WPF-UI if spike passes (`SelectedTime` binding, `MinuteIncrement`), else `TimeEditor` composite (hour/minute `NumberBox` + Now/Clear, `TimeSpan?` binding, range validation, keyboard-native).
- Chart: `ChartPalette.For(ThemeMode, bool hc, SKColor accent, SKColor text)` pure; VM subscribes `ISettingsService.Updated`, reads live resource colors with fallbacks, sets `LabelsPaint/SeparatorsPaint`, series `Stroke` (accent) + `GeometryFill`, chart `Background="Transparent"`; `ChartSummary` computed string + summary TextBlock.
- Localization: `Strings.*` per display string (en + de); XAML `{x:Static res:Strings.*}`; names untouched. New keys list reviewed in PR.
- Busy: `RunBusyDemo` 5 s + `CancelBusyCommand` (CTS); gallery Cancel button bound to busy state; Idle/cancelled status text.
- Residue rule: no LiveCharts references outside dashboard files (grep gate in matrix? assert via unit test scanning generated Clean? simplest: unit test asserting `DevTemWpf.App` dashboard-only files own the LiveCharts usings — actually simpler: existing matrix module checks + a grep in review. Decide: extend matrix-independent unit test `NoChartLeakTests` scanning src tree (excluding Dashboard* + pack) for `LiveCharts` — cheap and permanent.)

## 9. Test and CI plan

- Unchanged required gates: smoke, UI gate (counts must grow: +Data stops, +new cases), both template matrices, audits, remote trio.
- New unit: grid filter/sort/edit/validation/error states, tree expand/select/persist/10k, time parse/validate, palette mapping, localization completeness, busy cancel, no-leak scan.
- New UI: DataGrid cell edit + keyboard traversal, TreeView expand/select via keyboard, time set via mouse + keyboard, busy cancel round-trip, Data stops in `Visit_AllPages`, dashboard chart presence after theme switch (existing theme test extended or new assertion).
- Large-data: 10k VM filter correctness + timing note; page-level 10k toggle smoke (manual timed run recorded, not a flaky CI assertion).

## 10. Performance plan and budgets

- Same proxy machine; budgets: start ≤ 1.2 s, WS ≤ 150 MB, idle ~0%.
- 1k/10k: time VM filter application (in-test stopwatch, generous bound, correctness-first) + interactive feel note for 10k toggle; document mitigation (virtualization on, fixed table height on dashboard unchanged).
- No 8 GB claim.

## 11. Accessibility, resilience, and fallback plan

- DataGrid: keyboard traversal/edit/commit/escape native; validation errors as text (never color-only); row errors exposed via `IDataErrorInfo`.
- TreeView: native keyboard; items named by label; expand/collapse buttons + keyboard equivalents; persistence failure → default-collapsed (safe default).
- Time: keyboard-enterable + spinner buttons; invalid input → text error, value unchanged.
- Loading/error/empty states everywhere new; retry paths keyboard-reachable; reduced-motion untouched.
- Card-name toolkit gap (1.2.0 known issue) unchanged in scope; new surfaces use surfacing controls.

## 12. Dependency, license, and security impact
