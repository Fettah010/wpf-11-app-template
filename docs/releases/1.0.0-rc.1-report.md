## 3. Research and architecture decisions

- `PackageType=Template` hand packaging works; dotfiles need
  `NoDefaultExcludes`; `.ps1`-content warnings benign-by-design (suppressed
  with reason); root `template.json` glob depth matters (`..\..\`).
- `sourceName` does not cover `-n`-less item naming — item templates use
  their own `sourceName` (0.8.0 learning, applied).
- TextBlock UIA names: explicit `AutomationProperties.Name` replaces text
  content for `ByName` (probe-verified); suite adjusted, TESTING.md notes it.
- UI automation flake pattern (transient single-stop timeouts, green on
  retry) recorded; retries + Invoke-pattern + HasExited polling are the
  standing mitigations.
