## 3. Research and architecture decisions

- Gap tokens as `Thickness` (not the existing `Double`s): asymmetric
  bottom-flow gaps need Thickness; Doubles stay for scalar/code use
  (documented in `tokens.md`).
- Comfortable preserves the 1.1.0 rhythm exactly; Compact tightens
  (measured 9.04% Controls / 5.49% Settings pixel change) — tokenization
  without a surprise redesign.
- `0,4,0,*` optical lead-ins stay literal as the documented
  density-invariant exception; content sizes stay literal.
- Visual regression: custom LockBits comparer, zero packages (Verify
  rejected on post-2026-09-01 binary fee terms); Dashboard excluded
  (volatile timestamps); advisory-only in 1.2.0, gate decision → 1.3.0.
- Contrast: chain-integrity automation + documented contract + manual
  screenshot review (upstream values resolve inside theme dictionaries;
  no numbers invented).
- Card-name gap: `ui:Card` does not surface `AutomationProperties.Name`
  (all three card names absent maximized; inner content present) — kept in
  XAML (forward-compatible), covered by inner-element names, filed as known
  issue. Chart white-in-dark is D17 (→ 1.3.0), observed not fixed.
- Theme-test dropdown lesson: an open ComboBox popup swallows the next
  click — test now collapses explicitly (product behavior correct).
