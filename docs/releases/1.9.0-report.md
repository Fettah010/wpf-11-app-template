## Delivered in the working-tree candidate

- `SettingsService.LoadAsync` retains defaults recovery for missing files and
  malformed JSON, but propagates cancellation and other read failures. A
  locked-file regression verifies the unreadable settings file is unchanged.
- UI automation uses supported Invoke/SelectionItem patterns before click
  fallback and activates Settings before waiting for its shell selector.
- The generator test harness disables persistent MSBuild nodes, the MSBuild
  server, and shared compilation for isolated redirected child builds, then
  restores the caller's environment.
- Added the 1.9 migration/compatibility draft, deferred-work disposition
  register, support-policy wording, and refreshed dependency and performance
  records. Candidate 2.0 contract decisions remain explicitly unapproved.
