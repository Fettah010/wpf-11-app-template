## 6. Design and architecture

- **UI suite placement:** `tests/DevTemWpf.UiAutomation` (net10-windows,
  MTP + WpfFact STA). App path resolved relative to test binaries with
  existence guard (skip-with-message if unbuilt — never false-green in logs;
  CI builds first so present).
- **Headless policy:** `DEVTEM_RUN_UI_TESTS=0` (or non-interactive session)
  skips with console output; local runs execute. Report records both. If CI
  proves capable, the flag flips to run there too (evidence decides).
- **Binding guard:** `TestResources.Ensure` attaches a DataBinding
  TraceListener once per process; failures filtered to our assemblies/views;
  integration test asserts empty after page construction.
- **Settings write:** `LoadAsync` → `bool NeededPersist`; App persists only
  when true. Same observable behavior, less IO.
- **No new assemblies** in product (test project only).
