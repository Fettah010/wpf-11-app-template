## 3. Research and architecture decisions

- WPF-UI 4.3.0 / Mvvm 8.4.2 / Hosting 10.0.12 approved with 2026-10-14
  primary-source evidence → ADR-0001/0002.
- Correction vs roadmap snapshot: XAML Behaviors latest is **1.1.161**
  (not 1.1.142); deferred, recorded in `DEPENDENCIES.md`/D01.
- Test stack changed from plan draft during implementation: VSTest path
  (`Test.Sdk` + runner) **errors on .NET 10 SDK** for MTP projects
  (reproduced MSBuild error); migrated to xUnit v3 MTP mode
  (`xunit.v3.mtp-v2 4.0.2`, `global.json` test runner) per xUnit docs +
  Microsoft Learn `unit-testing-with-dotnet-test` (2026-09-12) → ADR-0004.
- One analyzer warning found and fixed (xUnit1051 → use
  `TestContext.Current.CancellationToken`).
