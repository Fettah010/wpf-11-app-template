## 3. Research and architecture decisions

- Next milestone is `1.1.0` (§8.1): verified via tags (`v1.0.0` latest), releases dir (no 1.1.0 plan), log head `53441ae`.
- No new packages (plan N03): re-audit confirms zero need; Hosting 10.0.13 patch explicitly deferred with rationale.
- `eng/check-ui-tests.ps1` stays repo-only (not packed): generated-app test paths rename (`DevTemWpf` → app name) so a hard-coded script path would break; generated suites inherit `Assert.Skip` honesty automatically.
- UI flake root cause (not a product bug): coordinate clicks missed when another maximized window covered the app. Fixed in test code (maximize + foreground at launch, Focus + WaitFor per click) — same mitigation family as the existing `Visit_AllPages` pattern. No product-code change for this.
- Cancelled update operations report `Idle`, not `Failed` (user asked to stop ≠ failure). `OperationCanceledException` without cancellation still maps to `Failed`.
