## 1. Outcome and success definition

A central token layer (colors, typography, spacing, radii, elevation,
icons) composed over WPF-UI — aliased, never patched — with runtime theme
switching (already live, now token-backed), compact density, accent
override, high-contrast compatibility, documented component standards, and a
token preview page. All app XAML moves off unexplained hard-coded style values.

Measurable success: `eng/smoke.ps1` green; Tokens page renders in
light/dark/system; density + accent changes apply live and persist; tests
≥24 passing; no new packages; contrast/focus notes published.

## 6. Design and architecture

- **Layers** (`App.xaml`, order matters): `ThemesDictionary` →
  `ControlsDictionary` → `SemanticColors` → `Typography` → `Spacing.*` →
  `Shapes`. Our dicts add `App*` keys only.
- **Dynamic vs static:** color/brush aliases → `DynamicResource` (theme
  follows); spacing/radii/type → `StaticResource` (density swaps whole dict).
- **Accent flow:** Settings change → `UpdateAsync` → `ThemeService`
  (theme+backdrop, then accent override/system) → `Changed` handler only
  re-applies accent on OS switches. Density flow: `settings.Updated` →
  MainWindow → `DesignTokenBootstrap.ApplyDensity`.
- **No new assemblies** (ADR-0003 holds); tokens live in
  `src/DevTemWpf.App/DesignTokens/`.
- **Contrast:** aliases inherit WPF-UI's designed pairs; accent text flips
  automatically (upstream threshold); custom accent + HC documented in
  `docs/design-system/themes.md`.

- Focus: visible Fluent focus via `FocusStrokeColor*` aliases; tab order
  nav→content→page; all preview/Settings controls named.

  still applies — documented as author responsibility, default stays system).
- Corrupt accent hex → validation message, no apply. Missing density dict →
  bootstrap falls back to Comfortable (defensive).

## 14. Risks and mitigations

| Risk | Mitigation |
|---|---|
| DynamicResource key typo → runtime-only failure | Page-construction WpfFact tests instantiate every page (XAML parse runs) |
| Alias to a key removed in future WPF-UI | Aliases enumerated in tokens.md with upstream file/line refs; 4.3.0 pinned; audit per milestone |
| Density swap misses a consumer (StaticResource cached pre-swap) | Swap replaces whole dictionary; smoke both densities; document rule (spacing always StaticResource from density dict) |
| Accent Changed-loop | Handler re-applies accent only (no Changed raised by accent update — source-verified) |
| Scope creep (controls/motion) | §5 + task mapping; extras → DEFERRED.md |
